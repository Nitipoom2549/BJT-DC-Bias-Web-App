สมการ Forward-Active

{% if mode == 'divider' %} VTH = VCC × R2 / (R1 + R2) RTH = R1 × R2 / (R1 + R2) IB = (VTH − VBE) / (RTH + (β + 1) × RE) IC = β × IB IE = (β + 1) × IB VE = IE × RE VB = VE + VBE VC = VCC − IC × RC VCE = VC − VE {% elif mode == 'fixed' %} IB = (VCC − VBE) / RB IC = β × IB IE = (β + 1) × IB VE = 0 V VB = VBE VC = VCC − IC × RC VCE = VC {% else %} IB = (VCC − VBE) / (RB + (β + 1) × RE) IC = β × IB IE = (β + 1) × IB VE = IE × RE VB = VE + VBE VC = VCC − IC × RC VCE = VC − VE {% endif %}

{% if mode == 'divider' %} Region: Cutoff เมื่อ VTH ≤ VBE · Saturation เมื่อ VCE ≤ 0.30 V (แก้สมการด้วย VCE = 0.30 V และ IC จาก RC/RE) · VBE นอกช่วง 0.50–0.90 V จะมีคำเตือนเพิ่ม {% else %} ถ้า IB ≤ 0 หรือ VCE ≤ 0.20 V ระบบจะแสดงคำเตือนว่าแบบจำลอง Forward-Active ใช้ไม่ได้ โดยไม่คำนวณค่า Cutoff/Saturation ในโหมดนี้ · VBE นอกช่วง 0.50–0.90 V จะมีคำเตือนเพิ่ม {% endif %}
